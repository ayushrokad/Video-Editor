# Community Research: Top User Feature Requests
Synthesized from across Reddit, Adobe UserVoice, and Blackmagic Forums:
1. **Lightweight Web/Remote Access:** Quick cuts without a 5 GB desktop install.
2. **Transparent Performance Telemetry:** Real-time dropped frames and hardware bottleneck indicators.
3. **Dual-Mode Timeline:** Instant toggle between traditional tracks and magnetic ripple.
4. **Universal Command Palette:** Fuzzy search for all tools and shortcuts (`Ctrl+K`).
5. **Integrated Clean Cache Sandbox:** Bounded storage limits preventing disk saturation.
