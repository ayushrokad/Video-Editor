# FRAMEFLOW — UX Laws for Professional Video Editing
**Document ID:** `UX-LAW-001`  
**Classification:** Core UX Interaction Laws  
**Version:** 2.0  

1. **Fitts's Law (Target Accessibility):** Primary transport and cutting controls (Play/Stop, Cut, Snapping) must have large hit areas or zero-travel keyboard shortcuts. The edges of panels must act as infinite magnetic targets.
2. **Hick's Law (Decision Time):** Minimize cognitive overhead by grouping contextual options into tabbed inspector views. Don't present 40 effects sliders at once; organize into collapsible sections.
3. **Jakob's Law (Familiarity):** Editors expect `J-K-L` to shuttle, `Spacebar` to play, `I/O` to mark points, and `Q/W` to ripple trim. Never break standard industry keystroke semantics.
4. **Miller's Law (Working Memory):** Limit visible information chunks. Use clean workspaces (`Media`, `Edit`, `Motion`, `Color`, `Audio`, `Deliver`) so the editor only focuses on the task at hand.
5. **Doherty Threshold (Response Time < 400ms):** UI scrubbing, cursor dragging, and playhead movement must respond in `< 16ms` (60fps) to keep the editor in an uninterrupted creative flow state.
