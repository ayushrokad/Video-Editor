## The Five Setting Tiers
1. **Tier 1:** Application Preferences (`Edit → Preferences`).
2. **Tier 2:** Workspace Settings (`Window → Workspaces`).
3. **Tier 3:** Project Settings (`Project → Project Settings`).
4. **Tier 4:** Sequence Settings (`Sequence → Sequence Settings`).
5. **Tier 5:** Object Properties (Contextual Inspector).
