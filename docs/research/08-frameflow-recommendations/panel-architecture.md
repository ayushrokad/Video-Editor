# FRAMEFLOW Panel Architecture Specification
See detailed geometry in [menus-and-panels-inventory.md](file:///h:/Ayush%20Work/Video%20Editor/docs/research/menus-and-panels-inventory.md#3-complete-panel-inventory--visual-layout-hierarchy).

## Layout Regions
- **Left Column:** Project Tree, Media Ingest, Smart Bins, Asset Search.
- **Center Top:** Dual Monitors (Source Monitor on left, Program Monitor on right).
- **Right Column:** Contextual Inspector (Transform, Effects, Color, Audio, Keyframes).
- **Bottom:** Multi-Track Timeline, Track Headers, Audio Waveforms.
- **Floating / Specialist Tabs:** Video Scopes, Audio Mixer, Graph Editor, Diagnostics.
