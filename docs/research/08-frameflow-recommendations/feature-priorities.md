# FRAMEFLOW Feature Prioritization Matrix (P0 to P3)
**Document ID:** `PRI-001`  
**Version:** 2.0  

| Priority | Capability / Feature | Milestone | Description |
| :--- | :--- | :--- | :--- |
| **P0 (Foundation)** | Media Browser, Source/Program Preview, Multi-Track Timeline | M0–M2 | Core editor shell, canvas rendering, viewport controls. |
| **P0 (Foundation)** | Contextual Inspector, Project Schema, Sequence Settings | M0–M3 | Object properties, transform controls, sequence resolutions. |
| **P0 (Foundation)** | Non-destructive Undo/Redo, Autosave, OPFS Storage | M3 | Crash resilience, state journaling, local storage sandbox. |
| **P0 (Foundation)** | WebCodecs Import, Frame Extraction, Local Playback | M4–M5 | Zero-upload video decoding, JKL transport, timecode sync. |
| **P1 (Core Editing)** | Track Targeting, Ripple, Roll, Slip, Slide, Snapping | M6 | Frame-accurate editing tools, dual-monitor trim loop. |
| **P1 (Core Editing)** | Markers, In/Out Points, Audio Waveforms, Multitrack Mix | M6–M8 | Audio scrub, peak meters, sub-frame trimming. |
| **P1 (Creative)** | WebGPU Shader Effects, Transitions, Keyframes | M7, M10 | Real-time compositing, blend modes, Bezier interpolation. |
| **P1 (Professional)** | Local Proxies, Relinking, Media Dependencies | M3–M4 | Offline/online proxy workflow, missing asset resolution. |
| **P2 (Specialist)** | Video Scopes (Parade, Vectorscope) & 3-Way Color Wheels | M11 | 32-bit float color grading, LUT import (.cube). |
| **P2 (Specialist)** | Motion Workspace & Inline Graph Editor | M10 | Speed/Value curves, spring/easing presets. |
| **P2 (Advanced)** | Multicam Editing & Synchronized Angles | M10 | Multi-angle video switching during live playback. |
| **P2 (Delivery)** | Cloud Rendering Dispatch & Multi-Format Muxing | M9 | Background FFmpeg export, ProRes/H.264 deliverables. |
| **P3 (Future)** | AI Transcript Editing & Auto-Captions | M12+ | Speech-to-text text-based cutting, silence removal. |
| **P3 (Future)** | Real-Time Cloud Collaboration & Review Links | M12 | Multi-user timeline presence, timecode comments. |
| **P3 (Future)** | Open Plugin Ecosystem & Shader Marketplace | M13+ | Community WebGPU shaders and transition packs. |
