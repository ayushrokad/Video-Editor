## Workspace Switching Philosophy
Unlike Resolve's locked full-page switches, FRAMEFLOW workspaces are layout arrangements of the same shared application state:
1. `Media`: Ingest, metadata, proxy generation.
2. `Edit`: Standard dual-monitor multi-track editorial.
3. `Motion`: Expanded Graph Editor and typography inspector.
4. `Color`: Video scopes, color wheels, and curves.
5. `Audio`: Multitrack console, mixer faders, and loudness meters.
6. `Deliver`: Render queue and export settings.
