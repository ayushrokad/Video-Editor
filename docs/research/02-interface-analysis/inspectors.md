## Contextual Selection Behavior
The Inspector adapts dynamically based on user selection:
- Single Video Clip: Transform, Opacity, Speed, Effects, Color, Audio, Keyframes.
- Multiple Clips: Multi-selection batch transforms, alignment, color labels.
- Text Layer: Font, tracking, styling, alignment, background box.
- Transition: Type, duration, alignment (Center, Start, End), curve shape.
- Empty Selection / Sequence: Displays master Sequence Settings summary.
