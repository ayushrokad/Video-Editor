# FRAMEFLOW Research Methodology & Evidence Framework
**Document ID:** `MET-001`  
**Version:** 2.0  

## 1. Principles of Inquiry
1. **Verification Over Hearsay:** Official product technical manuals, engineering whitepapers, and reproducible application states constitute primary evidence.
2. **Contextual Evaluation:** User feedback is analyzed within specific operational contexts (e.g. broadcast turnarounds vs solo YouTube creator deadlines).
3. **Continuous Expansion:** New research entries must be categorized using the standardized source register protocol before impacting product roadmaps.

## 2. Evidence Classification
- **Tier 1 (Authoritative):** Vendor technical documentation, W3C specifications, API schemas.
- **Tier 2 (Professional Applied):** Verified studio pipelines, guild workflows (ACE, MPEG), certified training curricula.
- **Tier 3 (Empirical Community):** Issue trackers, user forum bug reports, community survey data.
